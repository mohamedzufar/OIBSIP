## Completed Projects

### Task 2 — Unemployment Analysis with Python

**Status:** ✅ Completed

Analyzed unemployment trends across Indian regions and time periods, including regional averages, monthly trends, time-series analysis, correlation analysis, and pre-COVID vs COVID-period comparison.

**Technologies:** Python, Pandas, NumPy, Matplotlib, Seaborn, KaggleHub, Google Colab

**Key Areas:**
- Data loading and cleaning
- Exploratory data analysis
- Regional unemployment analysis
- Monthly trend analysis
- Time-series visualization
- Top 10 regional analysis
- Correlation analysis
- COVID-period analysis
- Data visualization

### Task 3 — Car Price Prediction Using Machine Learning

**Status:** ✅ Completed

Developed a regression model to predict used-car selling prices using vehicle characteristics and machine learning techniques.

**Technologies:** Python, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn, KaggleHub, Google Colab

**Models:**
- Linear Regression
- Random Forest Regressor

**Results:**

| Model | MAE | RMSE | R² |
|---|---:|---:|---:|
| Linear Regression | ₹133,098.53 | ₹261,925.34 | 0.6872 |
| Random Forest | ₹72,813.50 | ₹127,099.92 | 0.9263 |

### Task 4 — Email Spam Detection with Machine Learning

**Status:** ✅ Completed

Built an NLP-based classification system to distinguish spam messages from legitimate messages using TF-IDF and machine learning models.

**Technologies:** Python, Pandas, NumPy, Scikit-learn, TF-IDF, Naive Bayes, Logistic Regression, Matplotlib, Seaborn, Joblib, KaggleHub, Google Colab

**Key Areas:**
- Text preprocessing
- TF-IDF feature extraction
- Multinomial Naive Bayes
- Logistic Regression
- Model evaluation
- Confusion matrix
- Threshold optimization
- Error analysis
- Model comparison
- Model saving and loading

**Final Model Results:**

| Metric | Result |
|---|---:|
| Accuracy | 97.39% |
| Precision | 96.43% |
| Recall | 82.44% |
| F1-Score | 88.89% |
